<objective>
Self-host the three brand fonts so the visual identity survives a dead hotspot with zero network. Today `index.html` loads Instrument Serif, Manrope, and JetBrains Mono from `fonts.googleapis.com` — a CDN link that REQUIRES network. At the venue ("Internet Access: Not Provided"), if the hotspot drops, the entire typographic identity (a scored rubric item) silently falls back to system fonts. This plan replaces the CDN with bundled `@fontsource` packages and removes the Google Fonts tags, so the fonts ship inside the app bundle.

Purpose: Close ROADMAP Phase 5 Success Criterion #6 (the font half of FOUND-04 offline resilience). The fix carried forward from the Phase 1 cross-AI review.
Output: package.json (+@fontsource deps), src/main.jsx (+@fontsource css imports), index.html (Google Fonts tags removed).
</objective>
