## Typography

Two families, four load-bearing sizes. Fractional sketch values (13.5, 12.5) are normalized.
The kicker/step-counter tier is distinguished from body by UPPERCASE text-transform and 0.18em
letter-spacing — NOT by size. Merging 12px into 13px is invisible in practice.

| Role | Family | Size | Weight | Line Height | Where |
|------|--------|------|--------|-------------|-------|
| Prompt (question) | Pixelify Sans | 27px | 600 | 1.18 | Question prompt `h1` |
| CTA / slider value | Pixelify Sans | 17px | 600 | — | Continue / Show Me My Potential button; live slider value display |
| Body / option label | Manrope | 15px | 400 | 1.4 | Option pill labels, free-text input |
| Kicker / step / subtext / meta | Pixelify Sans + Manrope | 13px | 400 | 1.5 | Section kicker (Pixelify), step counter (Pixelify), subtext below prompt (Manrope), tension callout text (Manrope), slider min/max labels (Manrope), FreeText label (Manrope, weight 600 — see note), Going Global label (Pixelify), error copy (Manrope), check mark glyph (Pixelify) |

**Kicker differentiation rationale:** The kicker and step counter sit at 13px (same tier as subtext) but remain visually distinct via `text-transform: uppercase` and `letter-spacing: 0.18em`. Size is not the differentiator — tracking and caps are. This is standard practice for secondary-label tiers; the 12px size was unnecessary and has been merged up.

**FreeText label note:** The FreeText field label uses 13px Manrope at weight 600 (not 400) with `text-transform: uppercase; letter-spacing: 0.1em`. The weight 600 here is the same two-weight system — no additional weight is introduced.

Additional:
- Letter spacing: kicker = 0.18em; CTA = 0.04em; step counter = 0.06em; label/uppercase = 0.1em; Going Global label = 0.14em
- All caps: kicker text, label elements, vibe tags, Going Global label

## Motion Contract

All card transitions use Framer Motion `AnimatePresence` + `motion.div`.

### Card Transition (Framer Motion)

```js
// Variants (from 02-RESEARCH.md code examples)
const slideVariants = {
  enter:  (d) => ({ x: d > 0 ? 300 : -300, opacity: 0 }),
  center: { x: 0, opacity: 1 },
  exit:   (d) => ({ x: d > 0 ? -300 : 300, opacity: 0 }),
};
// Spring: { type: "spring", stiffness: 300, damping: 30 }
// AnimatePresence mode="wait"
```

Direction: `+1` = forward (Continue), `-1` = back (Back button).

### Other Animations

| Element | Animation | Duration / Easing |
|---------|-----------|-------------------|
| Kicker cursor blink | `steps(1) infinite` 1.05s | CSS keyframes |
| Idle sprite float | `ease-in-out infinite` 3.2s | CSS keyframes |
| Option hover slide | `translateX(2px)` | `transition: transform 0.08s` |
| CTA press | `translateY(4px)` | `transition: transform 0.06s` |
| Progress segment fill | color + shadow | `transition: all 0.3s` |
| Dealbreaker warning appear | opacity 0→1 | `transition: all 0.3s` |

### prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  /* Remove all transforms and animations */
  .kicker .cur { animation: none; opacity: 1; }
  .sprite       { animation: none; }
  /* Framer Motion: set transition duration to 0 in JS */
}
```

In the `QuizShell.jsx` Framer Motion config:
```js
const reducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
const transition = reducedMotion
  ? { duration: 0 }
  : { type: 'spring', stiffness: 300, damping: 30 };
```

## Accessibility Contract

| Requirement | Spec | Note |
|-------------|------|------|
| Tap targets | ≥44px all interactive elements | Back button: 44px hit area around 34px visual |
| Slider thumb | ≥28px | Applied via `input[type=range]` CSS in index.css |
| `--text3` (#505C6F) | Decorative / non-informational only | Fails WCAG AA — never use for copy |
| `--text2` (#8896AB) | Pass at 14px+ | OK for subtext and meta |
| `--text` (#EEF2F7) | Pass | All prompt + option label copy |
| Reduced motion | All keyframe + transform animations off | See Motion Contract above |
| Focus ring | `outline: 2px solid --accent; outline-offset: 2px` | On all interactive elements (keyboard nav) |
| Semantic HTML | `<button>` for all options and CTA | Not `<div onClick>` |
| `<h1>` on prompt | One `<h1>` per question card | Screen reader heading structure |

## Voice & Tone

Consistent with the product's advisory, direct, non-corporate stance:

- Direct, short sentences. No hedging language ("it might be," "you could potentially").
- Second person ("you," "your"). Never third person or corporate passive.
- Specific, not vague. "3 is a lot" not "this may limit results."
- Not cute or emoji-dependent. Pixel art carries the personality; copy is plain and confident.
- No exclamation points in warning or informational copy.
